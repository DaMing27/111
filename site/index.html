主线问题：机器学习为什么需要数学

我们以「机器学习为什么需要数学」为主线问题，研究「数学与算法基础」这一方向： 领域地图回答需要学哪些数学、各解决什么；生态地图回答去哪里学、用什么练； 认知地图回答怎么确认自己真的懂了。 我们选择「监督学习」作为典型任务，以「图像分类」作为直观的应用举例，并把基本问题扩展到模型评估、损失函数、特征表示等相邻问题； 模型训练的完整细节与深度数学推导暂不展开。 本主题为教学示例，其他小组可自行更换选题。

怎么用

  • 在三张地图中点击卡片查看详情；详情面板内的「相关条目」可以继续跳转，用 Esc 或「关闭」返回。
  • 在卡片详情里点「对此内容提反馈」，会打开预填好的 GitHub Issue 页面（需 GitHub 账号；也可复制内容发给小组）。
  • 地图内容与更新记录保存在仓库的 site/js/data.js 中；推送到 main 后由 GitHub Pages 自动发布。
  • 键盘操作：卡片可用 Tab 聚焦、Enter 打开，详情面板用 Esc 关闭。
